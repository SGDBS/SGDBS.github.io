### 创建

```python
# 1
keys = ['a', 'b', 'c', 'd']
values = [1, 2, 3, 4]
dic = dict(zip(keys, values))

# 2
dic = {'name':'Miku', 'number': 39}

# 3
dic = dict()

# 4 创建指定key的空字典
aDict = dict.fromkeys(['name', 'age', 'sex'])
```

### 访问及修改

```python
aDict['name'] # 如果存在则返回值，如果不存在则报错
aDict['name'] = 'Miku' # 如果不存在则创建，存在则修改value
```

* item() : 返回dict的(key,value)对
* keys() : 返回dict的key
* values : 返回dict的value

```python
aDict.get(key, val) # 如果存在key则返回值，否则返回指定的val
aDict.update({'a':97, 'age':39}) # 存在的修改，不存在的添加
```

### 删除

```python
del aDict['age'] # 删除
aDict.popitem() # 弹出并返回最后一个元素的value
aDict.pop('age') # 弹出并返回指定key的value
```
