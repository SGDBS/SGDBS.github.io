# Git从入门到大概会用 之远程仓库

#### 前言：

这是萌新在学习的时候随手记下的，便于日后使用。  
 当然也可以用来快速入门（大概）  
 详细的可以去看专业的教程  
 所以这里面**都是一些最基本的操作**  
 dalao还是不用看了

#### 开始：

一些比较基本的操作已经在上一篇博客中说了，有兴趣可以去[康康](https://blog.csdn.net/SGDBS233/article/details/112333608)

这篇文章主要介绍在Github上搭建远程仓库，且使用的是SSH加密传输

**0.创建SSHKey**

```
ssh-keygen -t rsa -C "YourEmai"
```

然后一路回车(否则会出现一些神奇的情况，建议自行去搜索一下教程）

**1.将SSH Key添加到Github账号**  
 在上述操作进行之后，在用户文件夹(C盘中的user目录里面有用户目录)中会出现两个文件:id\_rsa，Id\_rsa.pub(记得用vim，notepad++之类的东西打开)，其中，id\_rsa是私钥，不能泄露，id\_rsa.pub是公钥，可以告诉别人。  
 之后，在Github的个人主页中的“settings”中有个“SSH”之类的设定，在里边添加，将id\_rsa.pub中的内容复制进相应的文本框就行了。

**2.在Github上创建仓库**  
 在Github右上角加号那里，有个“Create a new repository”，创建。

**3.本地上传至Github：**  
 第一步：关联  
 第二步：上传文件

```
git remote add origin git@github.com:"Yourname"/"仓库名".git
git push -u origin master
```

注意，名字一定要填自己github的名字，仓库名也不要弄错  
 origin 是远程库的默认叫法。  
 第一次上传需要提交 -u 命令，即把分支也关联起来，之后就不需要了。  
 只需要

```
git push origin master
```

**4.Github传到本地**

```
git clone "仓库地址"
```

仓库地址是可以在仓库页面直接复制的
